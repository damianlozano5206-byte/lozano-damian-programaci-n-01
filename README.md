## Cómo clonar y utilizar el repositorio

Para obtener una copia del repositorio en otra computadora:

1. Copiar el enlace HTTPS del repositorio desde GitHub.
2. Abrir Visual Studio Code.
3. Abrir una terminal y escribir:

    `git clone [enlace HTTPS del repositorio]`

4. Entrar a la carpeta que se creó al clonar el repositorio.
5. Abrir los archivos desde Visual Studio Code para poder revisarlos o modificarlos.

Después de realizar cambios, se pueden guardar en GitHub utilizando los siguientes comandos:

    git add .
    git commit -m "Descripción de los cambios"
    git push origin main
